# 《独家童话》情侣宠物沉浸式页面新版设计思路

## 1. 新版核心方向

情侣宠物模块从原来的“多个功能页面 + 宠物局部展示”调整为：

> **1 个核心沉浸世界 + 若干功能模式。**

默认进入宠物模块时，不再让宠物只占约 40% 的页面，而是让宠物与房间场景接近 **100% 全屏展示**。页面尽量减少固定按钮，让用户首先看到的是“糯米生活在这里”，而不是一套游戏功能菜单。

核心目标：

> **打开这个页面后，用户会愿意先看它、摸它、逗它，而不是先找按钮。**

---

│      ├─ 玩耍

原设计中的“宠物互动页”不再必须作为独立页面存在，主要互动能力直接并入沉浸式主场景。

## 3. 沉浸式主页面布局

页面名称建议：

> **糯米的小屋**

默认页面结构：

```text
┌──────────────────────────────┐
│ ←         糯米的小屋      ··· │
│                              │
│       小满  ×  阿舟          │
│                              │
│                              │
│                              │
│            3D 糯米            │
│                              │
│                              │
│                              │
│                              │
│        「今天也想见你」       │
│                              │
│                         ◉    │
└──────────────────────────────┘
```

宠物、房间、家具、窗户、光线等 Godot 3D 内容应成为页面主体，React Native UI 只作为轻量覆盖层存在。

---

## 4. 页面 UI 原则

### 4.1 默认不展示大量功能按钮

沉浸状态只建议保留：

- 返回
- 页面名称
- 情侣关系标识（可弱化显示）
- 更多
- 少量宠物状态信息
- 一个轻量功能入口

原本的“喂食 / 摸摸 / 玩耍 / 换装”等固定按钮不建议长期占据底部空间。

### 4.2 功能入口采用轻量唤起

可使用右下角小型爪印按钮、轻点空白处或 Bottom Sheet 上滑手势唤起：

```text
◉
↓
玩耍
喂食
换装
布置
更多
```

使用完成后面板收起，重新回到完整沉浸状态。

---

## 5. 直接触摸宠物

主要交互不依赖功能按钮，而依赖直接触摸 3D 宠物。

隐藏碰撞区域：

```text
Pet
├─ HeadArea
├─ EarArea
├─ BodyArea
├─ PawArea
├─ BellyArea
└─ TailArea
```

不同部位产生不同反馈：

| 部位 | 推荐反馈 |
| --- | --- |
| 头部 | 闭眼、蹭手、尾巴轻摇 |
| 耳朵 | 抖耳、歪头 |
| 身体 | 回头看用户、靠近用户 |
| 爪子 | 抬爪、握手 |
| 肚子 | 翻身、躺下 |
| 尾巴 | 回头、躲开、追尾巴 |

连续摸头时进入 `PetHeadLoop`，持续一定时间可增加亲密度，并用轻量爱心粒子反馈。

---

## 6. 手势与 3D 查看

### 空白区域拖动

控制 Camera Orbit：

- 左右拖动：360° 查看宠物
- 上下拖动：有限角度调整视角
- 双指缩放：调整相机距离

### 手指落在宠物身上

优先进行身体区域 Hit Test，而不是旋转相机。

```text
Touch Start
      ↓
   RayCast
      ↓
碰到 Pet Collider？
   │           │
  YES          NO
   │           │
宠物互动    Orbit Camera
```

---

## 7. 宠物生命感

沉浸模式中，即使用户什么都不操作，宠物也应持续有轻微自然行为：

```text
Idle_Base
├─ Blink
├─ EarMove
├─ LookAround
├─ TailMove
├─ Stretch
├─ Yawn
└─ LickNose
```

建议每隔约 3～8 秒随机触发一个微动作，避免宠物像等待指令的 NPC。

宠物头部还可通过 Skeleton3D 的 Head Bone 有限跟随用户手指位置：

- Yaw：约 ±25°
- Pitch：约 ±15°

## 8. 喂食模式

喂食不再必须跳转到完全独立页面。

推荐：

```text
沉浸模式
   ↓
点击食盆 / 喂食入口
   ↓
Bottom Sheet 上滑
```

宠物仍在上方实时运行。

用户选择食物后：

```text
选择食物
↓
面板收起
↓
食盆出现
↓
糯米走过去
↓
低头吃东西
↓
舔嘴
↓
Happy
↓
Idle
```

---

## 9. 换装模式

换装属于明确的功能操作状态，因此宠物展示区域可缩小到约 **40%～50%**。

```text
┌──────────────────────────────┐
│ ←          给糯米换装         │
│                              │
│            3D 糯米            │
│       可旋转 / 可预览         │
│                              │
├──────────────────────────────┤
│ 衣服    配饰    小物          │
│                              │
│ [围巾] [蝴蝶结] [帽子] [...] │
│                              │
│        保存这身搭配           │
└──────────────────────────────┘
```

换装期间仍保留：

- Idle 动画
- 眨眼
- 摇尾巴
- 左右旋转
- 上下有限观察
- 双指缩放

服饰实际穿戴建议采用 Godot Socket / Attachment：

```text
Skeleton3D
├─ HeadSocket
├─ NeckSocket
├─ BackSocket
└─ TailSocket
```

---

## 10. 房间布置模式

房间布置是第二个适合半沉浸式操作的功能。

进入布置状态后：

- 上方约 50%～60%：3D 房间
- 下方：家具、墙面、地毯、小物分类
- 后续可增加拖拽家具到房间位置

Godot 负责家具实时摆放与场景预览，React Native 负责物品列表与 UI。

---

## 11. 任务、成长故事、成就、收藏、设置

这些属于内容型页面，可以继续保持独立页面。

### 任务

不建议采用纯游戏化任务，优先与《独家童话》主产品行为联动，例如：

- 双方今天都来看糯米
- 一起喂食一次
- 共同写下一篇日记
- 保存一张共同照片
- 纪念日当天来看糯米
- 连续陪伴 7 天

### 成长故事

记录：

- 第一次领养
- 第一次喂食
- 第一次换装
- 第一次共同布置房间
- 亲密度阶段
- 陪伴天数
- 与日记、照片、纪念日关联的宠物故事

### 成就

强调情侣关系与陪伴，而不是机械点击次数。

### 收藏图鉴

建议重新命名为：

> **糯米收藏册**

收藏宠物动作、装扮、家具、纪念物、成长故事和隐藏互动。

---

## 12. 页面状态模型

推荐统一成三种基础 UI 状态：

```text
IMMERSIVE
沉浸陪伴模式
宠物接近全屏

CUSTOMIZE
功能操作模式
宠物约 40%～50% + 底部功能面板

DETAIL
内容查看模式
成长故事 / 成就 / 图鉴 / 设置等
```

默认进入 `IMMERSIVE`。

状态切换：

```text
IMMERSIVE
   ↓ 点击换装
CUSTOMIZE
   ↓ 保存 / 关闭
IMMERSIVE
```

Godot 3D 场景尽量保持运行，React Native 主要改变覆盖 UI 和容器尺寸，避免频繁销毁、重建 3D Runtime。

## 13. 与现有 10 张设计稿的关系

旧版：

```text
60 宠物空间首页
61 宠物互动页
62 喂食页
63 任务页
64 宠物装扮页
65 房间布置页
66 成长故事页
67 成就页
68 宠物图鉴页
69 宠物设置页
```

新版建议：

- 60：彻底重做为全屏沉浸式「糯米的小屋」
- 61：主要能力合并进 60，不再必须作为独立页
- 62：改为沉浸场景 + Bottom Sheet 喂食模式
- 63：保留独立任务页
- 64：改为 40%～50% 宠物 + 底部换装面板
- 65：改为 3D 房间 + 底部布置面板
- 66：保留成长故事
- 67：保留成就
- 68：保留并重构为「糯米收藏册」
- 69：保留设置

## 14. 首张新版沉浸式设计稿方向

首张新版设计稿采用：

- 全屏温暖卧室 / 宠物房间
- 中央大比例 3D 糯米
- 奶油白、桃粉、暖木色
- 窗户自然光
- 花朵、相框、小熊、地毯等《独家童话》元素
- 顶部轻量标题「糯米的小屋」
- 情侣头像与“小满 × 阿舟”弱化展示
- 亲密度状态卡片弱化悬浮
- 点击头部、身体、耳朵、尾巴的交互提示
- 左右拖动 360° 查看
- 双指缩放调整距离
- 上下滑动调整视角
- 右下角只保留一个轻量爪印功能入口
